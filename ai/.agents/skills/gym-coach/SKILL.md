# Gym Coach

An evidence-based training reference synthesizing the gym/training wing of the fitness YouTube ecosystem across **ten channels and two wings**: the barbell/evidence-based five (physical therapy, biochemistry, kinesiology, sport physiology PhD, nutritional sciences PhD) and the calisthenics/bodyweight five (physiotherapist-led science-based calisthenics, skills and hybrid training, mainstream follow-alongs, mobility, and minimalist daily practice). One shared scientific backbone: mechanical tension, effective reps, volume management, and tendon-aware progression.

## How to Use This Skill

1. **Start with the synthesis**: [Synthesis](references/synthesis.md) — the consensus prescriptions, shared frameworks, disagreement map, and latent themes distilled across all five channels. Most questions are answered there.

## The Consensus Quick Reference

| Variable | Prescription |
|---|---|
| Volume | 10–20 hard sets / muscle / week (beginner 6–10, advanced 15–20+) |
| Frequency | ≥ 2× / muscle / week (3× small extra benefit) |
| Intensity | 0–3 RIR most sets; the last ~5 "effective reps" drive growth |
| Rep range | 5–30 works; 8–15 sweet spot; <5 inefficient for hypertrophy |
| Rest | 2–3 min compounds, 1–2 min isolation |
| Protein | 1.6–2.2 g/kg/day (up to ~3 g/kg in a cut); ~0.4–0.55 g/kg/meal; ~2–3 g leucine/meal |
| Surplus / Deficit | +300–500 kcal (massing) / −300–500 kcal, 0.5–1% BW/week (cutting) |
| Deload | Every 4–8 weeks at ~50% volume — mandatory |
| Sleep | 7–9 h, non-negotiable |
| Overload | Track lifts; progressive overload is the fundamental law |

Full table with sources and nuance: [Synthesis §1](references/synthesis.md).

## Coaching Defaults (when asked for advice)

1. Give the consensus prescription first, then the individual-channel nuance if relevant.
2. Name the training age (beginner / intermediate / advanced) — volume, failure proximity, and split advice all hinge on it.
3. Name the tool context (barbell/gym vs bodyweight/home) — route to the corresponding wing; the science is shared, the load mechanism differs.
4. When channels disagree, present the disagreement table (Synthesis §5) and resolve by goal, not by guru.
5. Anchor claims to the shared backbone (Schoenfeld volume/frequency/rep-range, Morton protein) rather than to personalities.
6. For bodyweight questions, respect the tendon economy: gate high-stress variations behind prerequisites and scaled progressions.
7. Never prescribe through pain: route injury questions to the Athlean-X diagnostic lens and recommend clinical care for anything structural.
